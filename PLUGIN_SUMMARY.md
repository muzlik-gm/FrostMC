# FrostSMP Plugin - Complete User Guide

## Overview
FrostSMP is a comprehensive Minecraft plugin featuring a Fragment-based elemental power system with 13 unique fragments, each providing custom abilities, visual effects, and progression mechanics for Paper/Spigot servers (1.20.4+). The plugin transforms Minecraft into a magical RPG experience with deep progression systems, stunning visual effects, and extensive customization.

### Fragment Activation Process (Detailed)

#### Step 1: Crafting Phase
- **Fragment Creation Recipe**: Craft using specific materials per fragment type
  - Fire: Blaze Powder + Fire Charge + Magma Cream + Nether Wart
  - Water: Prismarine Shard + Heart of the Sea + Kelp + Blue Dye
  - Air: Feather + Phantom Membrane + White Dye + Sugar
  - Earth: Diamond + Emerald + Stone + Brown Dye
  - Dark: Wither Skeleton Skull + Obsidian + Black Dye + Gunpowder
  - Light: Beacon + Glowstone + Yellow Dye + Gold Ingot
  - Void: Ender Pearl + End Stone + Purple Dye + Chorus Fruit
  - Storm: Lightning Rod + Blue Dye + Gunpowder + Redstone
  - Dragon: Dragon Breath + Dragon Egg + Red Dye + Blaze Rod
  - Time: Clock + Gold Ingot + Redstone + Yellow Dye
  - Mob: Bone + Leather + Green Dye + Rotten Flesh
  - Luck: Rabbit's Foot + Four Leaf Clover + Green Dye + Gold Nugget

#### Step 2: Ritual Construction
- **Build Ritual Area**: Use provided schematic file (Ritual_Area.schem)
- **Structure Requirements**:
  - 7x7 base platform of stone bricks
  - Central altar made of chiseled stone bricks
  - 4 corner pillars with beacon tops
  - Decorative elements: sea lanterns, end rods, carved pumpkins
  - Water channels connecting corners to center

#### Step 3: Ritual Execution
- **Material Placement**: Place Fragment Creation item on central altar
- **Activation**: Right-click altar with Ritual Catalyst (diamond item)
- **Ritual Timer**: 5-minute completion time with visual progress
- **Protection**: Area becomes grief-protected during ritual
- **Completion**: Receive Fragment Activator item upon success

#### Step 4: Fragment Unlock
- **Fragment Activator**: Right-click to permanently unlock fragment
- **Immediate Effects**: Fragment becomes available in GUI
- **Auto-Activation**: Fragment activates automatically on first unlock
- **Progression Start**: Begin at Level 1, Rank 1 with basic abilities

### Fragment Swapping System
- **Fragment Changer Recipe**: Ender Eye + specific materials
- **Ritual Process**: Same structure, different materials
- **Instant Swap**: No cooldown between fragment changes
- **Progress Retention**: All fragment levels/ranks preserved
- **Multiple Ownership**: Can own multiple fragments simultaneously

## Progression System (Detailed)

### Fragment Levels (1-50) - Power Scaling
**Level Progression:**
- **Levels 1-10**: Fast progression, 100-500 XP per level
- **Levels 11-25**: Medium progression, 500-1500 XP per level  
- **Levels 26-40**: Slow progression, 1500-3000 XP per level
- **Levels 41-50**: Very slow progression, 3000-5000 XP per level

**XP Sources:**
- **Passive Mobs**: 5-15 XP (Cow, Pig, Sheep, Chicken)
- **Hostile Mobs**: 15-50 XP (Zombie, Skeleton, Creeper, Spider)
- **Nether Mobs**: 50-100 XP (Blaze, Wither Skeleton, Ghast)
- **End Mobs**: 100-200 XP (Enderman, Shulker)
- **Boss Mobs**: 500-2000 XP (Ender Dragon, Wither, Elder Guardian)
- **Mini-Bosses**: 200-500 XP (Ravager, Evoker, Vindicator)

**Level Benefits:**
- **Damage Scaling**: +2% damage per level (up to +100% at level 50)
- **Mana Efficiency**: -1% mana cost per level (up to -50% at level 50)
- **Cooldown Reduction**: -0.5% cooldown per level (up to -25% at level 50)
- **Effect Duration**: +1% duration per level (up to +50% at level 50)

### Fragment Ranks (1-8) - Ability Unlocks
**Rank Thresholds:**
- **Rank 1**: Level 1 (Starting rank)
- **Rank 2**: Level 5 (Secondary abilities unlock)
- **Rank 3**: Level 10 (Enhanced effects begin)
- **Rank 4**: Level 18 (Advanced abilities unlock)
- **Rank 5**: Level 25 (Cinematic effects begin)
- **Rank 6**: Level 35 (Ultimate abilities unlock)
- **Rank 7**: Level 42 (Master-tier abilities)
- **Rank 8**: Level 50 (Maximum power achieved)

**Rank Benefits:**
- **New Abilities**: Each rank unlocks 1-2 new abilities
- **Enhanced Effects**: Existing abilities gain new visual effects
- **Increased Power**: Base damage and effects multiply by rank
- **Reduced Costs**: Higher ranks reduce mana consumption
- **Cinematic VFX**: Ranks 5+ trigger screen effects
- **Particle Density**: More particles and complex patterns

### Character Levels (Separate System)
**Character XP Sources:**
- **Fragment Usage**: Gain character XP when using abilities
- **Exploration**: Discover new biomes and structures
- **Achievements**: Complete plugin-specific milestones
- **Daily Activities**: Login bonuses and activity rewards

**Character Level Benefits:**
- **Mana Capacity**: +10 max mana per character level

- **Special Perks**: Unlock unique character abilities

## Ability System (Comprehensive)

### Ability Activation Methods
**Primary Method - Sneak + Right-Click:**
1. Hold Sneak (Shift) key
2. Right-click with any item or empty hand
3. Ability activates based on current slot selection
4. Visual feedback shows which ability activated

**Alternative Methods:**
- **Scroll Wheel**: While sneaking, scroll to cycle through abilities
- **Number Keys**: Direct ability selection (1-4 keys)
- **Custom Binds**: Configure in `/controls` menu
- **Voice Commands**: Optional voice activation (if supported)

### Ability Slot System
**4 Ability Slots Per Fragment:**
- **Slot 1 - Primary**: Basic offensive ability (Rank 1)
- **Slot 2 - Secondary**: Utility or enhanced ability (Rank 2-3)
- **Slot 3 - Advanced**: Powerful area ability (Rank 4-6)
- **Slot 4 - Ultimate**: Devastating ultimate ability (Rank 7-8)

**Slot Management:**
- **Auto-Assignment**: New abilities auto-fill appropriate slots
- **Manual Override**: Drag abilities between slots in GUI
- **Quick Switch**: Scroll wheel cycles through available abilities
- **Slot Indicators**: Action bar shows current slot selection

### Ability Scaling Formulas
**Damage Calculation:**
```
Final Damage = Base Damage × (1 + Level × 0.02) × (1 + Rank × 0.25)
```

**Mana Cost Calculation:**
```
Final Cost = Base Cost × (1 - Level × 0.01) × (1 - Rank × 0.05)
```

**Cooldown Calculation:**
```
Final Cooldown = Base Cooldown × (1 - Level × 0.005) × (1 - Rank × 0.1)
```

**Duration Calculation:**
```
Final Duration = Base Duration × (1 + Level × 0.01) × (1 + Rank × 0.15)
```

## Ritual System (Detailed Mechanics)

### Ritual Structure Requirements
**Base Platform Construction:**
- **Size**: 7x7 block area (49 blocks total)
- **Material**: Stone Bricks for the base platform
- **Pattern**: Solid platform with no gaps or holes
- **Height**: Must be built at ground level or higher
- **Clearance**: 5-block vertical clearance above platform

**Central Altar Setup:**
- **Position**: Center of the 7x7 platform (4,4 coordinate)
- **Material**: Chiseled Stone Bricks (3x3 area)
- **Height**: 1 block above base platform
- **Activation Point**: Center block where items are placed
- **Protection**: Becomes unbreakable during active rituals

**Corner Pillar Configuration:**
- **Positions**: Four corners of the platform
- **Height**: 3 blocks tall from base platform
- **Materials**: Stone Brick base, Beacon on top
- **Beacon Power**: Must be powered and active
- **Light Level**: Provides illumination for ritual area

**Decorative Elements:**
- **Sea Lanterns**: Placed at midpoints of platform edges (4 total)
- **End Rods**: Vertical placement on pillar sides (8 total)
- **Carved Pumpkins**: Decorative elements facing inward (4 total)
- **Water Channels**: 1-block wide channels connecting corners to center

### Ritual Types and Processes

#### Fragment Creation Ritual
**Purpose**: Create new fragments from raw materials
**Duration**: 5 minutes (300 seconds)
**Materials Required**:
- Fragment Creation item (crafted with specific materials)
- Ritual Catalyst (Diamond with custom model data)
- Beacon power for all 4 corner beacons

**Process Steps:**
1. **Preparation**: Build ritual structure according to specifications
2. **Material Placement**: Place Fragment Creation item on central altar
3. **Activation**: Right-click altar with Ritual Catalyst
4. **Ritual Start**: 5-minute timer begins, area becomes protected
5. **Progress Monitoring**: Boss bar shows completion percentage
6. **Completion**: Fragment Activator item appears on altar
7. **Cleanup**: 5-minute protection period for item collection

**Visual Effects During Ritual:**
- **Magic Circles**: Rotating geometric patterns above altar
- **Particle Streams**: Colored particles flowing from corners to center
- **Beacon Beams**: Enhanced beacon beams with fragment colors
- **Sound Effects**: Mystical humming and magical chimes
- **Lightning**: Occasional lightning strikes on altar (harmless)

#### Fragment Changer Ritual
**Purpose**: Switch between owned fragments instantly
**Duration**: 2 minutes (120 seconds)
**Materials Required**:
- Fragment Changer item (Ender Eye with custom model data)
- Target fragment selection (via GUI during ritual)
- Active beacon power

**Process Steps:**
1. **Structure Check**: Verify ritual area is properly built
2. **Item Placement**: Place Fragment Changer on altar
3. **Fragment Selection**: GUI opens to choose target fragment
4. **Activation**: Confirm selection to start ritual
5. **Quick Ritual**: 2-minute completion time
6. **Instant Switch**: Fragment changes immediately upon completion

### Ritual Protection System
**Protection Duration**: 5 minutes after ritual completion
**Protected Area**: 15x15 block radius around ritual center
**Protection Features**:
- **Block Breaking**: Prevented by non-ritual participants
- **Item Pickup**: Only ritual starter can collect items
- **PvP Protection**: Combat disabled in ritual area
- **Mob Spawning**: Hostile mobs cannot spawn in area
- **Explosion Protection**: TNT and creeper explosions blocked

**Cleanup Timer Display:**
- **Format**: "Ritual area protected for 4:32 remaining"
- **Updates**: Every 10 seconds with countdown
- **Warning**: 30-second warning before protection ends
- **Completion**: "Ritual protection has ended" message

### Ritual Failure Conditions
**Structure Damage:**
- **Detection**: Continuous monitoring of ritual structure
- **Failure**: If any required block is broken during ritual
- **Consequence**: Ritual stops, materials are lost
- **Prevention**: Structure protection during active rituals

**Power Loss:**
- **Beacon Failure**: If any beacon loses power during ritual
- **Redstone Issues**: If beacon pyramid is damaged
- **Consequence**: Ritual pauses until power is restored
- **Recovery**: Ritual resumes from pause point if fixed within 1 minute

**Player Absence:**
- **Distance Check**: Ritual starter must stay within 50 blocks
- **Timeout**: 30-second grace period if player leaves area
- **Failure**: Ritual cancels if player doesn't return
- **Exception**: Admins can override distance requirements
